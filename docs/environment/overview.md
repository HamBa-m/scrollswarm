# Formal Environment Model

ScrollSwarm is mathematically formulated as a **Decentralized Partially Observable Markov Decision Process with Networked Communication (Dec-POMDP-NC)**, defined by the tuple:

$$\mathcal{M} = \langle \mathcal{N}, \mathcal{S}, \{\mathcal{A}_i\}_{i \in \mathcal{N}}, \mathcal{P}, \{R_i\}_{i \in \mathcal{N}}, \{\Omega_i\}_{i \in \mathcal{N}}, \mathcal{O}, \mathcal{G}, \gamma \rangle$$

---

## Model Components

- **Agents ($\mathcal{N}$):** A set of $N \in [1, 10]$ rocket probes indexed by $i \in \{0, 1, \dots, N-1\}$.
- **Global State Space ($\mathcal{S}$):** The true configuration of the world at timestep $t$, encompassing the radiation sheath boundaries $y_{\text{ceil}}, y_{\text{floor}}$, active polygon asteroid positions, geometries, and velocities $\mathcal{A}_{\text{ast}}$, floating telemetry beacons $\mathcal{C}$, and agent coordinates $(x_i, y_i)$.
- **Action Space ($\mathcal{A}_i$):** Discrete vertical actuation $\mathcal{A}_i = \{\text{UP}, \text{STAY}, \text{DOWN}\}$.
- **Transition Probability ($\mathcal{P}$):** Deterministic vertical step dynamics ($k = 5\text{ px}$) combined with dynamic asteroid kinematics (Keplerian drift $v_x(R)$ and Hill's epicyclic vertical oscillation $y(t)$).
- **Observation Space ($\Omega_i$):** Ego-centric continuous observations $\mathbf{o}_i \in [0, 1]^{15}$ generated by a 7-ray forward LiDAR rangefinder.
- **Reward Function ($R_i$):** Configurable per-agent or cooperative team reward incorporating beacon acquisition, survival incentives, and crash penalties.
- **Communication Graph ($\mathcal{G} = (\mathcal{V}, \mathcal{E})$):** An undirected or directed graph dynamically pruned when probes terminate, enabling message passing prior to action selection.
- **Discount Factor ($\gamma$):** $\gamma \in [0, 1)$, typically $0.99$.

---

## The Scrolling Coordinate Frame

The simulation operates in a Cartesian viewport of width $W = 800\text{ px}$ and height $H = 400\text{ px}$ with top-left origin $(0, 0)$:

- **Horizontal Axis ($x$):** Probes maintain assigned column positions $x_i = \text{start\_x} + i \cdot \text{spacing}$. Ring debris and telemetry beacons drift horizontally from right to left with size-dependent drift speeds $v_x(R) \ge 1.0\text{ px/step}$.
- **Vertical Axis ($y$):** Probes maneuver vertically within $[y_{\min}, y_{\max}]$. Decreasing $y$ corresponds to climbing; increasing $y$ corresponds to diving.
