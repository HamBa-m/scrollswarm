# Formal Environment Model

ScrollSwarm is mathematically formulated as a **Decentralized Partially Observable Markov Decision Process with Networked Communication (Dec-POMDP-NC)**, defined by the tuple:

$$\mathcal{M} = \langle \mathcal{N}, \mathcal{S}, \{\mathcal{A}_i\}_{i \in \mathcal{N}}, \mathcal{P}, \{R_i\}_{i \in \mathcal{N}}, \{\Omega_i\}_{i \in \mathcal{N}}, \mathcal{O}, \mathcal{G}, \gamma \rangle$$

---

## Model Components

- **Agents ($\mathcal{N}$):** A set of $N \in [1, 10]$ quadcopters indexed by $i \in \{0, 1, \dots, N-1\}$.
- **Global State Space ($\mathcal{S}$):** The true configuration of the world at timestep $t$, encompassing the scrolling mountain ridge profiles $h_{\text{top}}, h_{\text{bot}} \in \mathbb{R}^W$, tree coordinates $\mathcal{T}$, floating targets $\mathcal{C}$, and agent coordinates $(x_i, y_i)$.
- **Action Space ($\mathcal{A}_i$):** Discrete vertical actuation $\mathcal{A}_i = \{\text{UP}, \text{STAY}, \text{DOWN}\}$.
- **Transition Probability ($\mathcal{P}$):** Deterministic vertical step dynamics combined with constant right-to-left scrolling ($\Delta x = -1\text{ px/timestep}$).
- **Observation Space ($\Omega_i$):** Ego-centric continuous observations $\mathbf{o}_i \in [0, 1]^{15}$ generated by a 7-ray forward LiDAR rangefinder.
- **Reward Function ($R_i$):** Configurable per-agent or cooperative team reward incorporating target acquisition, survival incentives, and crash penalties.
- **Communication Graph ($\mathcal{G} = (\mathcal{V}, \mathcal{E})$):** An undirected or directed graph dynamically pruned when agents terminate, enabling message passing prior to action selection.
- **Discount Factor ($\gamma$):** $\gamma \in [0, 1)$, typically $0.99$.

---

## The Scrolling Coordinate Frame

The simulation operates in a fixed Cartesian viewport of width $W = 800\text{ px}$ and height $H = 400\text{ px}$ with top-left origin $(0, 0)$:

- **Horizontal Axis ($x$):** Agents are stationary along their assigned column positions $x_i = \text{start\_x} + i \cdot \text{spacing}$. The entire terrain, trees, and targets scroll horizontally from right to left at speed $v_{\text{scroll}} = 1\text{ px/step}$.
- **Vertical Axis ($y$):** Agents maneuver vertically within $[y_{\min}, y_{\max}]$. Decreasing $y$ corresponds to climbing; increasing $y$ corresponds to diving.
